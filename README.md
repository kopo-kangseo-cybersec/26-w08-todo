# ✅ To-Do List

할 일을 생성하고, 완료 상태를 관리하며, 진행률을 한눈에 확인할 수 있는 반응형 단일 페이지 앱입니다. 브라우저 로컬 저장소(`localStorage`)를 통해 작업 내용을 유지하며, 반복 일정과 마감일 알림까지 함께 관리할 수 있습니다.

## 프로젝트 소개

이 프로젝트는 일정/업무 관리에 필요한 핵심 기능을 단순한 인터페이스로 구현한 웹 애플리케이션입니다. UI는 Tailwind CSS CDN을 활용하고, 동작 로직은 순수 JavaScript로 작성했습니다.

주요 목적:
- 할 일 추가 / 수정 / 삭제 / 완료 토글
- 필터링 및 검색으로 원하는 항목만 빠르게 확인
- 달성률 표시를 통해 현재 진행 상황 파악
- 마감일 기반 캘린더와 반복 일정 지원
- 브라우저 알림 옵션으로 마감일 알림 제공

## 주요 기능

- 할 일 생성, 수정, 삭제, 완료 상태 전환
- 전체 / 진행 중 / 완료됨 필터
- 검색어 기반 목록 탐색
- 우선순위, 카테고리, 정렬 옵션
- 월간 캘린더로 날짜별 일정 확인
- 매일 / 매주 / 매월 반복 작업 자동 생성
- 완료 항목 일괄 삭제
- 브라우저 알림 권한 허용 시 마감일 오전 9시 알림
- `localStorage` 기반 자동 저장 및 새로고침 복원
- 입력 길이 제한, XSS 방지, 빈 입력 방지 등 예외 처리

## 기술 스택

- HTML5
- Tailwind CSS CDN
- Vanilla JavaScript
- Browser API (`Notification`, `localStorage`)

## 실행 방법

1. 저장소를 로컬에 클론합니다.
2. 프로젝트 루트에서 정적 웹 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

3. 브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000
```

Tailwind CSS CDN을 사용하므로 인터넷 연결이 필요합니다.

## Bootstrap vs Tailwind

이 프로젝트는 Tailwind 버전을 선택해 구현했습니다. Tailwind는 클래스 기반으로 UI를 빠르게 구성할 수 있고, 컴포넌트별 스타일을 정교하게 제어하기 적합합니다. 반면 Bootstrap은 사전 정의된 컴포넌트 조합에 익숙해 빠르게 화면을 구성할 수 있지만, 세부 커스터마이징과 일관된 디자인 시스템 구성에는 Tailwind가 더 유리하다고 판단했습니다.

결론적으로, 본 프로젝트에서는 Tailwind를 사용해 반응형 레이아웃, 인터랙티브 상태, 카드형 리스트, 강조 컬러 디자인을 자연스럽게 표현했습니다.

## 커스터마이징한 부분

다음은 PRD를 기반으로 추가 보완한 내용입니다.

- 모바일 터치 편의성을 위해 버튼과 체크박스의 최소 클릭 영역을 44px 이상으로 유지
- 브라우저 저장소 접근 실패 시 사용자에게 명확한 오류 메시지를 표시하도록 처리
- 목록이 비어 있거나 필터 결과가 없는 경우 각각 다른 안내 문구를 보여주도록 구성
- 반복 할 일은 완료 시 다음 회차를 자동 생성하고, 월 반복은 해당 월에 동일한 날짜가 없으면 마지막 날로 보정
- 마감일 캘린더와 선택 필터를 연결해 날짜 단위로 할 일을 손쉽게 찾을 수 있도록 구성
- 사용자 입력을 그대로 HTML로 렌더링하지 않고 텍스트로 처리하여 XSS 방지
- 입력 값 길이 제한과 공백 입력 방지 로직을 추가해 UX를 안정화

## 참고 사항

- 브라우저 알림은 `localhost` 또는 HTTPS 환경에서 동작합니다.
- 모든 데이터는 사용자의 로컬 브라우저에만 저장되며, 서버 기반 데이터베이스와는 연동하지 않습니다.
- 이 앱은 단일 페이지 웹 애플리케이션 형태로 설계되어 추가적인 백엔드 없이도 빠르게 실행할 수 있습니다.
