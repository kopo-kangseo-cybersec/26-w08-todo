# ✅ To-Do 리스트

> 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 소개

일상과 학습, 업무 중 해야 할 일을 빠르게 기록하고 전체 달성률을 한눈에 확인할 수 있는 **웹 기반 개인 할 일 관리 애플리케이션**입니다. 별도의 서버나 로그인 없이 브라우저만으로 즉시 사용할 수 있습니다.

- **할 일 관리(CRUD)**: 입력창에서 `Enter` 키 또는 '추가' 버튼으로 할 일을 등록하고, 체크박스로 완료 상태를 전환하거나 개별·일괄('완료 항목 삭제') 삭제할 수 있습니다.
- **상태별 필터링 & 실시간 진행률**: '전체 / 진행 중 / 완료' 탭으로 원하는 항목만 모아 볼 수 있으며, 상단 요약 텍스트(`완료 N개 / 전체 M개 (XX%)`)와 진행률 바가 실시간으로 갱신됩니다.
- **데이터 자동 저장**: `localStorage`를 활용해 브라우저를 새로고침하거나 닫았다 열어도 기존 목록과 완료 상태가 그대로 유지됩니다.

## 어떻게 만들었나요

1. **PRD 작성**: 구현에 앞서 앱의 목표, 데이터 구조(`id`, `text`, `completed`, `createdAt`), 화면 상태, 예외 처리 기준 및 구현 제외 범위를 `PRD.md`로 정의했습니다.
2. **AI 검토로 PRD 보완**: 빈 칸 입력 차단(`trim`), 공백 없는 긴 문자열의 줄바꿈 처리, `<b>굵게</b>` 같은 HTML 태그 입력 시 XSS 방어(`textContent` 사용), 빈 상태(Empty State) 문구 분기 등 세부 예외 케이스와 8개 완료 기준을 보완했습니다.
3. **Plan 확인**: 보완된 PRD를 바탕으로 `index.html`, `style.css`, `script.js`의 역할 분리와 Tailwind CSS 유틸리티 매핑, 완료 기준 검증 계획을 먼저 점검했습니다.
4. **Agent 구현**: 확정된 계획에 따라 시맨틱 HTML 마크업, Tailwind CSS 레이아웃, 순수 Vanilla JS 상태 관리 및 렌더링 로직을 구현했습니다.
5. **dev에서 보완**: 모바일 화면(`375px`) 테스트를 거쳐 버튼 터치 영역을 넓히고, 새 항목 추가 시 부드러운 등장 애니메이션과 접근성 속성(`aria-*`)을 추가해 완성도를 높였습니다.

## Bootstrap vs Tailwind

- **화면 차이**: Bootstrap 버전은 기본 버튼·폼·리스트 그룹 컴포넌트 특유의 정형화되고 묵직한 느낌을 준 반면, Tailwind 버전은 세밀한 `slate` 색상 단계와 둥근 카드 여백, 부드러운 그림자가 어우러져 훨씬 깔끔하고 모던한 화면으로 완성되었습니다.
- **코드(HTML `class`) 차이**: Bootstrap은 `btn btn-primary`, `form-control`, `list-group-item`처럼 의미 단위의 짧은 컴포넌트 클래스를 사용해 HTML이 간결했지만, 세부 여백이나 색상을 바꿀 때 별도 CSS 덮어쓰기가 필요했습니다. Tailwind는 `flex items-center gap-3 p-3 bg-slate-50 rounded-xl`처럼 유틸리티 클래스를 조합해 HTML의 `class` 속성이 길어지는 대신, 파일을 오가지 않고 마크업에서 바로 반응형(`sm:`)과 세부 디자인을 제어할 수 있었습니다.
- **최종 선택 및 이유**: **Tailwind CSS 버전을 최종 선택**했습니다. 클래스 문자열은 길어지지만 기본 프레임워크 스타일과 충돌할 일이 없고, 모바일 뷰포트 대응과 미세한 UI 커스터마이징을 훨씬 빠르고 직관적으로 처리할 수 있었기 때문입니다.

## 커스터마이징한 부분

- **빈 상태(Empty State) 2단계 안내 분기**: 전체 할 일이 아예 없을 때(`"등록된 할 일이 없습니다..."`)와 필터링 결과만 없을 때(`"해당 상태의 할 일이 없습니다."`)의 안내 문구를 구분해 사용자 혼동을 줄였습니다.
- **입력 예외 및 보안 방어 강화**: `innerHTML` 대신 `textContent`를 사용해 HTML 태그 입력 시 스크립트나 태그가 실행되지 않고 문자열 그대로 출력되도록 처리했으며, `wrap-anywhere` 커스텀 유틸리티로 공백 없는 긴 문자열도 카드 밖으로 넘치지 않게 보완했습니다.
- **오늘 날짜 표시 및 인터랙션 개선**: 상단 헤더에 오늘 날짜(연·월·일·요일)를 자동 표시하고, `style.css`에 `fadeSlideIn` 키프레임 애니메이션을 추가해 새 할 일이 추가될 때 자연스럽게 나타나도록 개선했습니다.
- **모바일 터치 편의성 및 웹 접근성**: 좁은 모바일 화면에서도 오작동이 없도록 버튼 최소 높이(`min-h-[36px]`, `min-h-[42px]`)를 확보하고, `role="progressbar"`, `role="tablist"`, `aria-label` 속성을 적용했습니다.
