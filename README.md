# ✅ To-Do 리스트

## 소개

할 일을 추가하고, 완료 상태를 관리하며, 전체 진행률을 확인할 수 있는 반응형 단일 페이지 앱입니다. 목록과 알림 설정은 브라우저의 `localStorage`에 저장됩니다.

## 구현

- 화면과 동작은 HTML, Tailwind CSS CDN, Vanilla JavaScript로 구현했습니다.
- 할 일 추가·수정·삭제·완료 토글, 필터, 완료 항목 일괄 삭제를 지원합니다.
- 마감일 월간 캘린더, 검색, 우선순위·카테고리 필터, 정렬, 매일·매주·매월 반복 항목을 지원합니다.
- 선택적으로 브라우저 알림 권한을 허용하면 앱이 열린 동안 마감일 오전 9시에 알림을 표시합니다. 브라우저 알림은 localhost 또는 HTTPS에서 지원됩니다.
- 입력은 100자로 제한하고, 사용자 입력을 HTML로 실행하지 않고 텍스트로 렌더링합니다.

## Bootstrap vs Tailwind

이 저장소에는 요청에 따라 Tailwind CSS CDN을 사용하는 버전이 구현되어 있습니다. Bootstrap 버전은 포함되어 있지 않아 두 버전의 화면이나 코드를 직접 비교하지는 않습니다.

## 실행 방법

프로젝트 폴더에서 간단한 정적 웹 서버를 실행한 뒤 브라우저에서 엽니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다. Tailwind CSS CDN을 사용하므로 실행 시 인터넷 연결이 필요합니다.

## 커스터마이징

- 모바일 화면의 터치 편의성을 위해 버튼과 체크박스에 최소 44px의 클릭 영역을 적용했습니다.
- 저장 데이터가 손상되었거나 브라우저 저장소에 접근할 수 없는 경우 사용자에게 오류를 표시하고 기존 저장 데이터를 임의로 덮어쓰지 않습니다.
- 전체 목록과 필터 결과가 비어 있는 경우 서로 다른 안내 문구를 표시합니다.
- 반복 할 일은 완료할 때 다음 회차를 새 항목으로 생성하며, 월 반복은 다음 달에 같은 날짜가 없으면 해당 월의 마지막 날로 조정합니다.
